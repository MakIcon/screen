# Проверка локализации

`pnpm lint:i18n` проверяет видимые строки в JSX, подписи и подсказки, а также покрытие словарём вариантов редактора оформления. Имена продуктов, форматы, рабочие команды и примеры адресов исключены явно в `scripts/check_localization.mjs`. Пользовательский текст, названия файлов и содержимое серверов не переводятся.

`pnpm test:i18n` проверяет совпадение ключей и параметров RU/EN, склонения, числа, обращения к пользователю, тексты ошибок, стадии установки и подписи редактора. `pnpm test:web` запускает проверку исходников перед всеми тестами интерфейса.

Новые обычные элементы интерфейса используют `useTranslation`. Для неизменяемых описаний и вариантов редактора есть `useAppearanceText`: английская подпись сопоставляется с типизированным ключом из `localizationKeys.ts` и переводится при отрисовке. При добавлении такой подписи обновляются оба словаря `appearance.ru.ts` / `appearance.en.ts` и таблица ключей. Собственные подписи пользователя и имена шрифтов через этот механизм пропускать нельзя.

Для проверки размеров запустите `pnpm dev` и откройте [страницу проверки](http://localhost:1420/scripts/localization-preview.html). Она показывает настоящий редактор в отдельном окне предпросмотра шириной 560, 640 или 900 пикселей. Кнопка проверки проходит по разделам и редактору градиента, измеряет переполнения кнопок и панели действий. Проверьте русский и английский языки. Не нажимайте «Сохранить и применить»: для проверки достаточно временного предпросмотра.

Ошибки команд передаются как `{ code, detail }`. Интерфейс выбирает перевод по `code`, исходный `detail` сохраняется для диагностики. В настольном приложении журнал находится в `%APPDATA%\ScreenLauncher\logs\launcher-errors.jsonl`. Отмена определяется по коду и не считается ошибкой. Неизвестные коды получают понятное общее сообщение; технический текст не подставляется в уведомление.
