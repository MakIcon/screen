# OBS Telemetry 1.1.0

Поддержаны 17 релизов Minecraft Fabric: 1.21, 1.21.1, 1.21.2, 1.21.3,
1.21.4, 1.21.5, 1.21.6, 1.21.7, 1.21.8, 1.21.9, 1.21.10, 1.21.11,
26.1, 26.1.1, 26.1.2, 26.2, 26.3. Для каждого собран отдельный JAR.
Снапшоты, Forge и NeoForge в этот пакет не входят.

## Изменения

- Раздельная сборка для remapped 1.21.x и unobfuscated 26.x. Учтён
  переименованный метод ResourceKey в 1.21.11. Java 21 / Java 25 соответственно.
- Одна задача выборки в очереди игрового потока и один HTTP-запрос одновременно.
  При ошибках соединения пауза увеличивается до пяти секунд, затем связь
  восстанавливается автоматически.
- При остановке сервиса сохраняется токен сессии. Повторный запуск с теми же
  настройками сохраняет порт, если он доступен. Смена порта требует перезапуска
  игры, поскольку JVM-параметры задаются при её запуске.
- Установка мода в сборку использует транзакцию с откатом. Файлы других модов
  не удаляются. Устаревшие JAR 1.0.0 убраны из ресурсов репозитория.
- Сервер ограничивает число одновременных клиентов и размер HTTP-заголовков,
  проверяет Content-Length до чтения тела и задаёт таймауты записи.
- Старый неиспользуемый HTML-оверлей удалён. Рабочий оверлей скрывает данные
  старше трёх секунд. Запросы выполняются последовательно, с таймаутом и
  увеличением интервала при ошибках.
- `/overlay.json` передаёт данные без диагностического журнала. Отдельные
  виджеты загружают только нужные изображения. Прочность окрашивается по
  оставшемуся проценту; здоровье учитывает максимальный запас игрока.
- Обновлены экран настроек, статус соединения, карточки источников, индикация
  копирования, русские подписи, адаптация узкого окна и фокус клавиатуры.
- Добавлена установка из ZIP с проверкой SHA-256, размеров и имён файлов,
  защитой от выхода за папку распаковки и сохранением предыдущего пакета при
  ошибке. Добавлены генератор каталога и CI-сборка всех 17 версий.

## Проверка

- Все 17 JAR собраны локально на JDK 26.0.1 с Loom 1.15.4. Проверены точные
  зависимости Minecraft в каждом JAR и версии байткода Java 21 / 25.
- `pnpm typecheck`, ESLint для изменённых компонентов и проверка локализации.
- Веб-тесты: 67 файлов, 485 тестов прошли.
- Rust: 158 тестов прошли, два сетевых теста оставлены отключёнными.
- Clippy с запретом предупреждений; форматирование Rust; production-сборка Vite.
- Собран Windows EXE в release-режиме с `tauri/custom-protocol`.
- В браузере проверены экран настроек, реальные текстуры из JAR Minecraft 26.3,
  отдельный виджет здоровья, копирование адреса, потеря и восстановление связи.
  Данные игрока в браузерной проверке были тестовыми. При ширине 480 px список
  источников остаётся доступным с верхней части страницы.

Каждая версия проверена компиляцией, а не отдельным входом в игровой мир.
CI на GitHub будет запущен после отправки изменений в репозиторий.

## Файлы и установка

- `dist-release/obs-telemetry-1.1.0/ScreenLauncher.exe` — обновлённый лаунчер.
- `dist-release/obs-telemetry-1.1.0/screenlauncher-obs-telemetry.zip` — пакет.

Откройте обновлённый лаунчер, затем «Расширения → OBS Telemetry» и установите
ZIP. Если пакет уже установлен, кнопка «Обновить пакет» предложит выбрать ZIP.
Перезапустите экземпляр Minecraft Fabric, чтобы он загрузил новый мод.

Пакет не опубликован онлайн: URL новых JAR в каталоге намеренно пусты. После
публикации реальных файлов генератор каталога принимает неизменяемый базовый
URL через `-DownloadBaseUrl`. Удалённые ветки, релизы и пользовательская
установка расширения в рамках этой задачи не изменялись.
